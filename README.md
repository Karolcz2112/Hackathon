# Kosmiczny kurier — Godot 4

## Uruchomienie
1. Zainstaluj Godot 4 ze strony https://godotengine.org/download/.
2. W Godot wybierz **Importuj** i wskaż plik `project.godot` z tego folderu.
3. Otwórz projekt i naciśnij **F6** lub przycisk uruchamiania projektu (**F5**).

Gra nie wymaga dodatkowych grafik ani dźwięków. Rysuje elementy bezpośrednio w kodzie.

## Sterowanie
- **← / →** lub **A / D** — poruszanie statkiem
- **Mysz albo palec** — przeciąganie statku
- **Spacja** lub kliknięcie — rozpoczęcie / ponowne rozpoczęcie gry

Zbieraj złote gwiazdki, unikaj asteroid i spróbuj pobić swój rekord. Wynik jest zapisywany lokalnie.
